> **Premier IT Training & Career Transformation Academy**

---

## 🌟 Overview

**EndowIT Academy** is an industry-first IT educational platform built to bridge the gap between academic theory and real-world high-scale production engineering. Designed with a modern, high-tech aesthetic (Deep Navy, Electric Cyan, and Rich Slate), this website delivers a seamless user experience (UI/UX) with complete search engine optimization (SEO).

### 📚 Featured Courses & Subpages
1. **Full Stack (Backend Mastery)** (`#/courses/full-stack`): Node.js, Express, Go/Python FastAPI, PostgreSQL, MongoDB, Redis, Kafka, Docker, Kubernetes, AWS, and Distributed System Design.
2. **Artificial Intelligence & Machine Learning (AI & ML)** (`#/courses/ai-ml`): Deep Learning, PyTorch, Transformers, Generative AI, LLMs, Enterprise RAG, LangChain, and Autonomous Agents.
3. **Data Science Specialization** (`#/courses/data-science`): Python, Pandas, Applied Statistics, Machine Learning (Scikit-Learn, XGBoost), PySpark Big Data, and MLOps.
4. **Data Analytics & Business Intelligence** (`#/courses/data-analytics`): Advanced Excel, Industrial SQL, Power BI (DAX), Tableau dashboards, and Business KPI Modeling.
5. **Performance Digital Marketing & Growth Hacking** (`#/courses/digital-marketing`): SEO, Google Ads (PMax), Meta Ads (CBO), Google Analytics 4 (GA4), GTM, and AI Marketing.

## 🌐 5 Core Pages & Structure

* **Home (`/`)**: Hero section, Live Admissions Banner, Placement Metrics, Featured Courses, 4-Stage Learning Roadmap, Alumni Success Stories from top tier firms (Razorpay, Swiggy, Cognizant), Hiring Partners marquee, and interactive FAQ.
* **Courses (`/courses`)**: Full catalog with instant live search, category filters (Development, Data, AI, Marketing), and detailed Course Comparison Matrix.
  * **Course Subpages (`/courses/:slug`)**: In-depth module-by-module curriculum accordions, tools mastered, target job roles, prerequisites, and syllabus download CTA.
* **About Us (`/about`)**: Mission, Vision, 4 Educational Pillars, Faculty Profiles (Staff Architects & AI Researchers), and ISO/NASSCOM Accreditations.
* **Blog (`/blog`)**: Technical deep-dives on Microservices, Enterprise RAG, Career Roadmaps, and Performance Marketing with an interactive in-browser article reader.
* **Contact Us (`/contact`)**: Interactive inquiry form with live validation, WhatsApp direct connect, phone lines, campus map, and visiting hours.

## 🛠️ Tech Stack

* **Frontend:** React 18, Vite
* **Routing:** React Router v6 (`HashRouter` for zero-configuration GitHub Pages hosting)
* **Styling:** Tailwind CSS with custom glowing tech palette (`brand-dark`, `brand-cyan`, `card-tech`)
* **Icons:** Lucide React
* **SEO:** Dynamic meta tags, OpenGraph, Twitter Cards, semantic HTML5, and Schema.org JSON-LD

## 🚀 Quick Start (Local Development)

```bash
# 1. Clone the repository
git clone https://github.com/naveenmurugesan500-crypto/EndowIT.git
cd EndowIT

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

---

## 📦 Building for Production

```bash
npm run build
```
This generates the optimized production bundle inside the `dist/` directory ready for deployment.

---

## 🌍 Free Hosting on GitHub Pages

1. In your repository on GitHub, go to **Settings** &rarr; **Pages**.
2. Under **Build and deployment** &rarr; **Source**, select **GitHub Actions** (or deploy the `dist` branch).
3. The site will be instantly live at:  
   `https://naveenmurugesan500-crypto.github.io/EndowIT/`
